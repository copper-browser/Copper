MCP server, built in

Bring your own agent.

Copper runs an MCP server on your Mac. Claude Code, Codex, phi or any MCP client can drive the browser you're signed into, on the model and subscription you already pay for. Copper draws where each agent is about to click and puts the agent's badge on its tab. Press Stop to take the browser back.

  • Playwright MCP tool names. The tools use Playwright MCP's names and arguments, so a skill written for it works here unchanged.
  • One switch turns it on. Settings › Agents › Let agents drive this window. Set up connects Claude Code or phi in one press, and you never paste a token into a prompt.
  • A copper command for the shell, linked into your PATH by Homebrew. It never starts Copper on its own.
  • Loopback only. The server needs a bearer token that only your user can read. Pages in other browsers can't reach it.

Jev, built in

Jev acts in 300 ms, on your key.

Give Copper a goal. Jev reads the page's controls, picks an operation and an element in about 300 ms, and acts. A small model writes any text it has to type.

Jev runs on your own TypeSafe key. Any text it types comes from your Claude account or any OpenAI-compatible gateway.

  • TypeSafe key
  • Claude account
  • OpenAI-compatible gateway
  • Haiku, Sonnet or Opus

  • Four Jev tools on the MCP server

    jev_runjev_stepjev_observejev_extract

    Run a goal to the end, take one step at a time, see the page the way Jev sees it, or pull structured values out of it. Copper never uses the model's output as a selector, a coordinate or JavaScript.

  • Start it from an agent or a terminal

    Type /jev <goal> in Claude Code or phi, or copper run "goal" in a terminal. The goal goes to Jev on the first call. It doesn't need a tab list or a snapshot first.

  • One click to set up

    In Settings › Agents › Terminal agents, press Set up for phi or Claude Code, or Install for the CLI. Copper writes the config and the command.

  • You can see who is driving

    A pill on the page says Jev is driving, and the driver timeline (⌥⌘J) shows each cycle as Jev reads, asks, acts and settles. Press Stop and Jev stops before its next action.

A run on Wikipedia.

We started on Wikipedia's Copper article and gave Jev one sentence, asking it to search for patina and stop at the article.

Jev took three actions. It clicked Search, a small model wrote the word, and Jev picked the article from Wikipedia's suggestions. It stopped once the article was on screen.

  1. CLICKSearch372 ms
  2. TYPE“patina” into Search Wikipedia290 ms + 1.3 s text
  3. CLICKPatina, change of object's surface…268 ms
  4. DONE, 96% sureverify it yourself

DONE means Jev thinks it finished. The tool tells your agent to check the page before reporting that it worked.

Sign-in for agents

Agents log in, 2FA included.

Connect Bitwarden and your agents can use your saved logins and two-factor codes, on your Mac or on a headless Mac mini. The agent never sees the password, and you decide which logins it can use.

  • You choose what's shared. Logins in Bitwarden's Agents folder are shared. A copper-agent: deny field blocks a login for good. Agents can't change either rule.
  • Nothing secret comes back. A sign-in reports which fields it filled. It leaves out the password, the code and the session key.
  • Cards and addresses too, with browser_autofill. Copper uses Bitwarden's bw client, so there is no extension to install.
The browser

Arc's features, on WebKit.

Copper has spaces with their own animated themes, Favorites, Saved and Today, folders, tab groups, split view, a ⌘K command bar and auto-archive.

It uses the WebKit that ships with macOS, so it doesn't bundle a copy of Chromium.

  • ⌃NNew space
  • ⌃1Jump to a space
  • ⇧⌘DSplit view
  • ⌘KFind any tab

What's built in.

Copper has no toolbar, start page, suggestion feed or account. Ad blocking, reading mode, element hiding and picture in picture are built in, and most have a shortcut.

  • One field

    ⌘L

    Addresses, searches with the engine you pick, sums, doc.new and !bangs. The field sends nothing until you press Return.

  • Tabs on top or on the left

    ⇧⌘S

    Pinned tabs shrink to a letter. Tabs from your last session don't load until you click them.

  • Spaces

    ⌃N

    Each space is a set of tabs with a name, an icon and a sidebar colour. A space can have its own profile.

  • Find any tab

    ⌘K

    Lists your open tabs by name as you type, including tabs in other spaces.

  • Hide parts of a page

    ⇧⌘H

    Click a cookie banner or a newsletter overlay to hide it. On your next visit it is hidden before the page draws.

  • Reading mode

    ⇧⌘R

    Strips a page down to the article.

  • A built-in ad blocker

    Trackers and ad networks are blocked at the network level, so their content never loads. It is on by default and you can turn it off per site.

  • Picture in picture

    ⇧⌘P

    Moves the video into a small window that stays on top of other apps.

  • Passwords in your keychain

    ⌥⌘L

    Copper saves a password after the sign-in works. It offers it when you click the field and fills it when you pick it. macOS encrypts it.

  • Automatic updates

    A new build is downloaded and verified in the background. Copper restarts only when you tell it to.

Flow

Import from Chrome or Arc.

Flow is one button. It reads the other browser's files on your Mac without changing them. Imported tabs don't load until you open them. macOS asks you once before Copper can use the other browser's key.

Chrome extensions run here

Paste a Chrome Web Store link, or press Add on the extension's page. It runs on WebKit's own extension engine, the one Safari uses, and Copper fills in the Chrome APIs WebKit lacks. Needs macOS 15.4 or later.

Canvas

A multiplayer canvas in a tab.

Canvas is a whiteboard that opens in a tab. It holds stickies, text, frames, arrows, images and live websites. Your Personal canvas is stored on your Mac and works offline.

Link Copper Cloud to share a board and you see everyone's cursors, including the agents'. The ⌘E agent, MCP agents and the copper command can all read and write boards. People without Copper can join from any browser with Canvas App.

  • ⌃⇧ENew canvas
  • ⇧⌘OPersonal canvas
Canvas App

Canvas App runs in any browser.

The canvas is its own open source project, canvas-app. Copper ships its page, and Canvas App is that page running in Chrome, Firefox, Safari or Edge with no install. It stores your boards in the browser, works offline and joins shared boards with live cursors.

MITAll of the canvas code is in one MIT licensed repository.

One file to hostThe app is one HTML file. You can serve it from the server that hosts your canvases.

Copper Cloud

Run your own Copper Cloud.

Copper Cloud is the sync server. It is one Rust binary and Postgres, and it installs with one command on any Linux machine or with Terraform on AWS. It syncs spaces, tabs, bookmarks and history between your Macs and hosts live canvas rooms.

curl -fsSL https://raw.githubusercontent.com/copper-browser/copper-cloud/main/install.sh | sudo sh
  • Off until you turn it on. You pick what syncs, and passwords are never synced.
  • Pinned by its certificate. Copper shows the fingerprint before it sends anything.
  • Encrypted at rest with your account's key, on a machine you run.
Privacy

What leaves your Mac.

Copper requests the pages you ask for, their icons, and an update check at launch and every six hours. When you run Jev, the page's controls and your goal go to TypeSafe on your own key, and the model provider you chose writes the text it types. Copper Cloud is off until you link a server you run.

AccountsCopper has none. Copper Cloud accounts live on your own server.
TelemetryOne anonymous ping a day (version, macOS, chip; no ID, no IP kept) so we can count users. Off in Settings › Privacy. No analytics, no crash reports.
ServersWe don't run one. Your tabs, history and passwords stay on the Mac or on a machine you run.

Questions.

What does it cost?

Nothing. Copper is free and open source under the MIT license.

Do I need an AI subscription?

No. Copper is a whole browser without one. Agents are optional: Claude Code, Codex, phi or any MCP client drives it on the plan you already pay for, once you turn on Settings › Agents › Let agents drive this window.

Is it safe to open?

Copper is ad-hoc signed and not yet notarized by Apple, so macOS asks before the first launch. Homebrew and the one-line installer clear that for you. After a manual download, run xattr -cr /Applications/Copper.app once, or right-click Copper and choose Open. The source is on GitHub if you'd rather build it yourself.

What does it send?

The pages you ask for, their icons, and an update check at launch and every six hours. Once a day, an anonymous ping with Copper's version, macOS version and chip counts active users; turn it off in Settings › Privacy. Copper has no other analytics, no crash reports and no account. Jev and Copper Cloud send only while you use them. What leaves your Mac

And this website?

It has no analytics, trackers or cookies, and loads nothing from other sites. Privacy

Is it Safari?

No. Copper uses the WebKit that ships with macOS, the engine Safari uses, with its own window, sidebar and features. It doesn't bundle a copy of Chromium.

Do Chrome extensions work?

Yes, on macOS 15.4 or later. Paste a Chrome Web Store link, or press Add on the extension's page. It runs on WebKit's own extension engine.
