## CI/CD

The canvas pin check and hourly bump, the 6-hourly upstream sync and the signed release (`.woodpecker/release.yaml`, on the macOS agent: `RELEASE=1` or a `v…` tag; `DRY_RUN=1`; docs/releasing.md) run on **Roadrunner** (Exowatt's Woodpecker + Dagger CI, `.woodpecker/`). `sync-fork.yml` stays on GitHub Actions for now, and the site deploys with GitHub Pages (`site.yml`). Check Roadrunner builds with `gh rr status`, `gh rr watch`, `gh rr logs`, `gh rr rerun` (install: `gh extension install Exowatt-Labs/gh-roadrunner && gh alias set rr roadrunner --clobber`) — `gh run` only sees GitHub Actions. Console: https://cicd.apps.exowatt.com.
