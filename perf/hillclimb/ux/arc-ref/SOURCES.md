## Not found (no public Arc picture of a comparable surface)

- **Dark theme** — Arc has no app-wide dark chrome; its sidebar takes each space's theme colour. Compare Copper dark against Arc's darker space themes (main-sidebar is not one).
- **Top-tab layout** — Arc has none (sidebar only). main-top / cmdk-top / split-top have no Arc pair.
- **History, bookmarks and passwords panels** — Arc has no panels for these (history is a Chrome-style page; no bookmarks; passwords in Settings).
- **Password save offer** — Arc's is Chromium's bubble; no clean public screenshot found.
- **Move in (import) sheet** — Arc's import step exists only in screen-recording sites behind logins (pageflows, pablooo); not fetched.
- **Error page, update prompt** — none found.
- **Agent pill / driver card / ⌘E pane** — Arc has no agent; the nearest is Dia (a different product), so left out.
